# Blockbench character animation

The chibi character study is integrated into production. The avatar creator, portraits and world players share its customizable 120px component atlases and five native animation clips in four directions.

See [Characters](characters.md) for the atlas format, state selection, rendering and verification commands, and [the migration record](blockbench-migration.md) for review evidence. Editable production models are in `scripts/characters/blockbench/models`.
