# Blockbench characters

This is the production character pipeline for the avatar creator, portraits and world sprites.

```sh
pnpm assets:characters
pnpm assets:characters:review
pnpm e2e:characters
```

- `geometry.cjs`, `head.cjs`, `model.cjs`: native mesh geometry, anime faces and rig.
- `hair.cjs`, `headwear.cjs`: fourteen hair silhouettes and eight fitted headwear choices.
- `body.cjs`, `clothing.cjs`, `wardrobe.cjs`, `customization.cjs`: body, garment details and coordinated materials.
- `statement-tops.cjs`, `statement-bottoms.cjs`, `statement-shoes.cjs`: ten additional wardrobe families with 30 interchangeable pieces.
- `animations.cjs`: idle, walk, sit, listen and sit-listen keyframes.
- `render.cjs`: 120px cel-shaded frames, outlines, anchors and depth maps.
- `generate.mjs`: Blockbench generation and installation of all 172 component atlases.
- `review.mjs`: native model round trips and game-size appearance sheets.
- `headwear-review.mjs`: every hair/headwear pairing from four directions with headphones on and off.
- `appearance-review.mjs`: hair, face and outfit sheets at native and game sizes.
- `face-review.mjs`: isolated creator checks for all options, playback, compact layouts and saving.
- `creator-review.mjs`: served atlas checks, all creator options, save/reload and compact layouts.
- `expansion-check.ts`, `layout-review.ts`: all 30 statement pieces in the creator and game, plus scrolling, touch targets and keyboard navigation at eight viewport sizes in both themes.
- `comparison.mjs`: before/after screenshots at their original display sizes.
- `playwright-check.mjs`, `world-check.ts`: live creator/save checks and world state checks.

Editable outputs are in `models/`; `manifest.json` records their appearance and atlas paths. A component can be regenerated by passing its name, for example `node scripts/characters/blockbench/generate.mjs hair/twintails-catears`. The full command is required after shared geometry, camera, rig or atlas changes.

Every outfit has one upper-body component, named `upper/<outfit>`. All appearances share the same body and can mix every component. Generation rejects component names outside the current inventory.

Generation needs the Blockbench web app and starts no development server. Review commands use the existing game client. See [character rendering and verification](../../../docs/characters.md).

`hair_tail` and `scarf` bones give the pearl braid and traveler jacket secondary motion in all five clips. They retain the shared frame dimensions, foot/hip anchors and component depth composition.

`review.mjs`, `headwear-review.mjs`, `appearance-review.mjs` and `playwright-check.mjs` accept `--output=<directory>` to preserve before/after evidence. `appearance-review.mjs --hair=bob,pixie` limits a draft review to selected cuts. The refinement evidence is in `artifacts/avatar-anime`.
